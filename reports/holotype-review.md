# Holotype extraction — human review

Generated by the Sonnet agent extraction pass against cached Wikipedia
articles in `node_modules/.cache/genus-wikipedia/`.

This file contains:

- **Low confidence (~55)** — agents found candidates but couldn't commit
  with high confidence. Each entry has the candidate(s), agent's guess
  at type/institution, and the issue blocking auto-application.
- **No information found (~17)** — agents found no usable specimen ID.
  Where possible, the agents extracted primary-literature references for
  manual lookup.

The cached wikitext for any genus listed here is at:

```
node_modules/.cache/genus-wikipedia/<Genus>.wikitext
```

To resolve an entry, edit the genus YAML directly. The schema rules
(post-#1848 / #1849 / #1850):

- `specimen_id` is `Array<string>` — at least 1 element when present
- `specimen_type` ∈ {`holotype` (1 ID), `lectotype` (1), `neotype` (1),
  `syntype` (≥2), `unknown`}
- `institution` required when `holotype` block is present, unless `status`
  is set to `destroyed`/`lost`/`uncatalogued`/`unknown`
- For multi-element single-individual holotypes, canonicalize to the first
  ID and note the range in `material`

Once an entry is resolved, you can delete it from this file.
