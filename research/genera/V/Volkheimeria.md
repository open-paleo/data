# *Volkheimeria*

## Is "Cañodon Asfalto" a different unit from the Cañadón Asfalto Formation?

*2026-08-06*

**Conclusion.** No. It is a misspelling in one table, carried from the first edition of *The Dinosauria* into the second. Governs `location.formation: Cañadón Asfalto` on [*Volkheimeria chubutensis*](../../../genera/V/Volkheimeria.yml).

**Evidence.**
- pol2022a, p. 138: "*Volkheimeria chubutensis* was found in the Cañadón Asfalto Formation".
- mcintosh1990a, Table 16.1: "V. chubutensis Bonaparte, 1979b | Cañodon Asfalto Formation, Chubut, Argentina | Callovian".

**Ruled out.**
- *A separate "Cañodon Asfalto" unit.* Upchurch and colleagues (2004) print "Cañodon Asfalto Formation (Chubut), Argentina" (upchurch2004a, Table 13.1), the same spelling in the same table row as McIntosh (1990). It is one table repeated, not an independent reading.

**Open.** Nothing.
